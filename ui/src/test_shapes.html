Terminator

Marks the start or end of a flow.

Subroutine

A named, predefined process such as a called module.

Connector

An inspection or reference point on the flow.

Collate

Arranges data into a standard order or format.

Process

Any general processing step.

Preparation

A setup step, such as initializing a value or a switch.

Off-page connector

Links to a process continued on another page.

Sort

Arranges a list of items into sequence.

Decision

A branch point between two or more paths.

Display

Data shown to a person, such as on a screen.

Off-page connector

Links to a process continued on another page.

Merge

Combines multiple sets of data into one.

Delay

A pause or wait built into the process.

Manual input

An operation performed by a person, not automated.

Off-page connector

Links to a process continued on another page.

Database

A structured store of information that can be queried.

Data

Any input or output data in the flow.

Manual loop

A sequence repeated manually until stopped.

Off-page connector

Links to a process continued on another page.

Internal storage

An internal storage device.

Document

Data that can be read by people, such as a printout.

Loop limit

Marks the start of a loop (flip to mark its end).

Or

Multiple documents

Stored data
